# Production relay corpus captures

These fixtures are generated by an authenticated, read-only kind:9 query and
committed only after deterministic sanitization. Stable event IDs, pubkeys,
Room IDs, timestamps, message bodies, and free-form tag values are replaced;
event order, tag names/arity, reply aliases, byte-size metadata, and burst
scale remain.

Capture a Room through an existing member runtime without printing its key:

```sh
npm run capture:relay-corpus -w @beeline/buzz-client -- \
  --runtime /path/to/runtime.json \
  --room ROOM_ID \
  --output src/read-model/fixtures/captures/incident-name.json
```

Add the generated filename to `manifest.json`. CI re-signs every manifest
fixture with synthetic identities before running decode → reduce → select.
