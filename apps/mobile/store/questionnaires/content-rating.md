## App Store age-rating / review notes draft

- Category: Developer Tools / Productivity.
- Age rating: answer No to product-authored violence, sexual content, profanity,
  gambling, medical treatment, and unrestricted web access. Flag user-generated
  messaging if the current App Store form asks about it.
- Account: GitHub sign-in is available; reviewers need an owner-provided test
  account or a test Room invitation before review. Do not place credentials in
  this file.
- Moderation: Room access is controlled by the user's own Beeline service and
  membership. There is no public social feed or public user directory in the
  app.
- Reporting/blocking: confirm the actual pre-release behavior before filing. If
  a store form requires public UGC reporting/blocking features, escalate rather
  than making a claim this code does not support.
