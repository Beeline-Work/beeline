# Welcome card frames

- `before-archived-tour.png` is a prior real mobile app render from `docs/evidence/onboarding/05-first-room-tour-card1-mobile.png`. It shows the older onboarding tour design, not sample data from this change.
- `after-card-1.png` through `after-card-4.png` are real Expo Web app renders at 390 × 844, captured with `chrome-devtools-axi` from a temporary preview route that was removed before commit.
- The Room and Corner transcripts in cards 1 and 2 are explicitly synthetic fixtures, rendered with the app's `LedgerEntry` and `IdentityMark` components. No actual messages, check run, or pull request was created for the screenshots.
- The 25 tool marks are exactly the selection in `Tools.dc.html`; the DeepSeek mark is the official Simple Icons vector from `simple-icons/develop/icons/deepseek.svg`.
- Cal.com uses its official square app mark from `https://cal.com/android-chrome-512x512.png`, and Coinbase uses its official favicon mark from `https://www.coinbase.com/favicon.ico`, rendered at the same 30 px size as the other marks.
