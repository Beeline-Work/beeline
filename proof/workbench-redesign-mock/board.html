Workbench Visual Redesign

Design Board: Instrument Panel Concept

Visual Concept: Instrument Panel
Each tool is an instrument reading. Status communicates through: (1) Position: terminal states align right; (2) Weight: active/connecting states use bold; (3) Form: distinct glyphs (circle/dot/x/check) for each state; (4) Color is secondary, supporting but never the sole signal. Each tool cell carries ONE compact Connect button, aligned directly on the side of the cell.
