## Core invariants (read first)

- **Production relay may answer a multi-value `#h`/`#d` filter with matches for only one key.** Every fan-out in mobile transport and `packages/buzz-client` expands to one single-key filter per key inside ONE batched `query([...])`/subscription; fake relays answer multi-key filters first-key-only (`monolith-rig-transport.test.ts`, `client.test.ts`).
- **Local stack vs production:** `git-url.ts` maps `git://` markers to `https://`, unusable against the local docker stack (`relay-stack/compose.yml`, http 127.0.0.1:3010) — pair repo-less and invite top-level Rooms. That stack includes a credential-free materializer, so local RoomView reads stay on 3010. Mobile's `getEffectiveRelayUrl()` honors the embedded runtime URL when no device override exists, and `BuzzClient` treats loopback/Android-host relay URLs as the intentionally open local relay instead of waiting forever for a NIP-42 challenge; coverage: `buzz-identity-storage.test.ts`, `client.test.ts`. - **Private Workspace pairing does not require a relay-wide membership gate.** `visibility='invite-only'` maps to NIP-29 `private`; an outsider redeems the globally readable kind:30078 marker through the authenticated `/agent-pairing/claim` server boundary, which atomically verifies the marker's current member author and reserves it for that exact key before the client publishes canonical kind:9000 membership. Acceptance proof: `npm run prove:private-pairing` against the ordinary open local relay.

## Branch conventions

- **Corner agents own the GitHub workflow.** Finish means commit, push, `gh pr create`, print the URL, wait for the server checks-passed fact. With no human hold the agent merges with `gh`; the merge webhook archives and reaps the worktree.
- `fm/*` branches stack; check `gh pr list --json baseRefName,headRefName` before assuming a file is on `main`; `git branch -a --contains <commit>` finds the source branch.
- A cherry-pick off `feature/*` can drop a context-only declaration — `npm run typecheck` catches it. Stale `fm/*` merges conflict mostly on `relay-stack/web/dl/` artifacts — pick either, regenerate with `npm run bundle:beeline`.
- **Resolve merges as one batch gate:** enumerate every textual conflict and semantic overlap first, resolve the complete set in one pass, then run one integration matrix plus a single conflict-resolution review before push.
- **`TYPECHECK` (root `npm run typecheck` = turbo + the isolated mobile app + `tsconfig.scripts.json`) gates every PR unfiltered by path** — the one gate with no path filter: two independently green PRs can merge cleanly into a red `main`, so a required-field change on a shared row type must re-run the root typecheck after merging `origin/main`.
- **Stacked PRs merged base-first do not propagate** — re-target to `main`; verify with `git grep <symbol> origin/main`.
