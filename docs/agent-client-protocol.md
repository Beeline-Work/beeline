# Client protocol invariants

- **Phone reads and writes share one authenticated live WebSocket.** Each operation sends a request id and settles on its matching reply; the approved HTTP exceptions live in `apps/mobile/network-channels.json`. `BuzzRigTransport` is an alias of `MonolithRigTransport`.
- **An unanswered operation fails at its existing request deadline.** `LiveConnection.request` covers authorization, socket opening and the complete reply; a deadline tells the shared connection state the socket is suspect. It never retries the operation or falls back to HTTP. Optional Room requests wait for the existing Room-draw barrier before dispatch. Vault secret submission stays on HTTP so Fly replay reaches the helper's own server without storing secrets in PostgreSQL.
- Community and Room tenancy authority: `community.ts` and server-stamped `channels.community_id`. Workspace membership covers every live top-level Room. In a two-member agent DM every human message addresses that agent (`routeHumanMessage`).
- **App links** live in `web/.well-known/` (paths/packages: `scripts/app-associations.mjs`; drift: `app-association-drift.yml`). Store review uses `beeline://review/<secret>`; the HTTPS form is a fallback.
