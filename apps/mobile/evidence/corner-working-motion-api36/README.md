# Corner working motion — Android API 36

Captured from the real Beeline Android development build on `emulator-5554`
(API 36), backed by the local server projection rather than component fixtures.

- `room-list-working-waiting.png` shows the expanded Room row with a brass,
  motionless `WAITING` corner and a neutral-ink `WORKING` corner.
- `pinned-working-frame-a.png` and `pinned-working-frame-b.png` are consecutive
  frames of the pinned working line, captured roughly half a pulse cycle apart.

The floating Tools control is supplied by the Expo development client and is
not part of Beeline's application UI.
