# Settings identity tile seat

Phone-width (390) before/after of the Settings identity tile wearing a loud
square photo. Person photos stay darkflighted in the product, so a generated
creature plate cannot prove the seat — these frames paint the same square the
Workspace #1549 proof used.

- `before.png` — shipping treatment: 64px square inset in the 76px brass bezel,
  overflow hidden on the tile, no radius on the picture.
- `after.png` — the same tile seated by `workspacePictureSeat(IDENTITY_SETTINGS_TILE)`
  (inner radius 18, margin 4, picture radius 14).

Regenerate with `node apps/mobile/scripts/render-identity-picture-seat-frames.mjs`.
