# Phone API operation inventory

Phase A names the phone's future server operations without changing transport. The type authority is `PhoneOperationMap` in `src/phone-operations.ts`. Every operation is domain-specific; there is no event-query or event-publish escape hatch.

## Durable reads

The extracted RoomView DTOs and guards cover the existing `workspaces`, `workspace`, `agent`, `chats`, `room`, `corners`, `history`, `invite`, and `claimAgentPairing` reads in `packages/buzz-client/src/room-view.ts`. Live invalidation remains off-path in Phase A.
