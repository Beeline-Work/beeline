# Fresh-context brief and review trials

On 2026-09-25, seven separate `codex exec --ephemeral --ignore-user-config --skip-git-repo-check -C /tmp -s read-only` sessions (Codex v0.155.1, `gpt-6-astra`) received the emitted release-managed skill text and one scenario each. One complex-plan trial was repeated after a skill correction, leaving six final scenarios. These are behavioral skill trials, not live Room-to-corner or deployed-harness tests. The reviewer trials could judge only the evidence supplied in their prompts and did not call `approve_merge` or write validation records.

| Trial                             | Input and observed result                                                                                                                                                                                                                                                                                                                                                                                 | Scope of proof                                                                                                    |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Precise button fix                | “Change the message action label from Remove to Delete; leave the confirmation and accessibility wording unchanged.” The agent returned `dispatch`, a compact brief retaining both exclusions, and no question.                                                                                                                                                                                           | A2 behavioral proof.                                                                                              |
| Ambiguous ban                     | “Ban this person from the Room.” The agent returned `clarify` and asked whether to remove the person only or also prevent rejoining.                                                                                                                                                                                                                                                                      | A3 behavioral proof.                                                                                              |

The agent returned `dispatch` without another go-ahead, retained those decisions, and identified the absent server object ID for the mock. The first trial invented an extra feedback criterion; the skill was tightened and the second trial did not repeat it. | Proportional confirmation and decision-preservation proof in a fresh context; no repository implementation proof. |

The supplied diff and tests covered only budget removal, with green CI.
