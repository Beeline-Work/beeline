# Product

## Register

product

## Users

People coordinating software work with linked autonomous agents from a mobile device. They need to move quickly between Workspaces, discuss work in Rooms, steer active Corners, and approve exact changes without confusing conversational access with merge authority.

## Product Purpose

Beeline makes multi-person, multi-agent software work visible and controllable from a phone while preserving a fail-closed human merge boundary. Success means Workspace and Room membership feel ordinary and legible, agent work stays observable, and no friendly UI affordance weakens the security spine.

## Brand Personality

Mechanical, alien, assured. The interface should feel like a restrained monochrome hull: tactile, information-dense, and calm under operational pressure.

## Anti-references

Avoid colorful status-only semantics, generic SaaS cards, decorative gradients, glassmorphism, playful consumer-chat styling, and interfaces that make agents appear to hold human merge authority.

## Design Principles

- Make Workspace, Room, and Corner boundaries unmistakable.
- Put the next operational action where the user is already looking.
- Reveal detail progressively without turning navigation into a maze.
- Encode state redundantly through text, glyph, contrast, geometry, and haptics.
- Keep conversational convenience separate from authority and approval.

## Accessibility & Inclusion

Do not rely on color alone. Preserve readable contrast, native accessibility roles and labels, 44-point touch targets, reduced-motion behavior, and haptics as supplementary feedback only.
