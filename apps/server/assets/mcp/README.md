## Member defaults (2026-10-31)

- `grok-bot.svg`: white circle and black eyes matching the approved Grok Bot default face; separate from the Grok corporate mark. Also the default bot face for Cursor and for any AI app without a known logo (approved 2026-11-05).
- `muse.webp`: Muse's own sheep doll portrait, supplied in the approved brief (SHA256 cac0f5be9beb8cea3aedcc345d65a92f4f50cf097b205206f0209a4021ee9b91). Replaces the app squiggle for default member identity.
- `codex.png`: OpenAI's published GitHub organization avatar, https://avatars.githubusercontent.com/u/14957082?s=256. Uses the OpenAI mark for Codex identification.
- `claude.png`: existing Claude mark from `apps/mobile/sources/assets/images/icon-claude@3x.png`.
- `openai.svg`: the OpenAI mark, from the approved External agent info pages mock (2026-11-05). Used for ChatGPT in Connectors and as its member default picture.

- `goose.png`, `pi.svg`, `opencode.svg`, `hermes.svg`, `gemini.png`, `zcode.png`: copied from `web/marketing/logos/`, the website-supported agent marks; provenance is recorded in `web/marketing/logos/provenance.json`.

Company marks identify the connected apps, without implying endorsement. Custom member portraits are never replaced by these defaults.
